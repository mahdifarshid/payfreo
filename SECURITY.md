# Security policy

PayFreo is pre-alpha software for local and testnet development. It has not completed an independent
security review and must not be used with real funds.

Please report suspected vulnerabilities privately to
[mahdifarshid2015@gmail.com](mailto:mahdifarshid2015@gmail.com). Include a concise reproduction and
the affected commit or version. Do not post exploit details in public issues, submit secrets, or use
real assets while testing. No response deadline, bounty, or production security guarantee is
offered.

The first Core foundation exposes health checks only. Payment verification, authentication, and
webhooks are planned work with separate security gates in [DEVELOP.md](DEVELOP.md).
